# Lecciones Aprendidas

Hallazgos relevantes del desarrollo que no encajan en una categoría más específica
(estándar, regla de negocio, ADR, patrón o perfil del proyecto). Cada entrada es un hecho
puntual descubierto en una feature, no una regla obligatoria para todo el equipo.
